# Personal Portfolio Website

## About the Project

This is my personal portfolio website created to showcase my education, technical skills, projects, resume, and contact information.

I developed this website as part of my learning and career preparation to present my skills and projects to recruiters and potential employers.

## Technologies Used

* HTML
* CSS
* JavaScript

## Features

* Home section
* About Me section
* Education details
* Technical Skills
* Projects section
* Resume section
* Contact section
* Responsive and user-friendly design

## Project Structure

```text
personal-portfolio/
│
├── index.html
├── style.css
├── script.js
├── images/
├── resume.pdf
└── README.md
```

## How I Built This Project

* **HTML** was used to create the structure and content of the website.
* **CSS** was used for styling, layout, colors, spacing, and responsive design.
* **JavaScript** was used to add interactive functionality.

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
